# Internationalization

UI strings should go through a thin message catalog so locales can be added later.

## Current state

- Default locale: English (`en`)
- Coach speech comes from recorded voice packs. Prompts in the phrase registry are
  English, but a pack can be recorded in any language (`meta.json` `language`);
  see [VOICE_PACKS.md](VOICE_PACKS.md). Word order is fixed by `phrasing.rs`, so
  languages that order numbers differently need phrasing changes.

## Usage

```ts
import { t } from "../shared/i18n";

t("live.startMonitor"); // → "Start live monitor"
```

Add keys to `src/shared/i18n/en.ts`. Do not hard-code user-visible English in new
UI when a key already exists (or add one).
